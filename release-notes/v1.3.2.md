ArkStore on Android, Windows, macOS, Linux, iPhone and iPad.

**Which file?** Android: **arm64-v8a** fits almost every phone (not sure? take **universal**). Windows: the **windows-x64-setup.exe** (or the **.msi**). Mac: the **.dmg** for your chip (**arm64** for Apple silicon, **x64** for Intel). Linux: the **.AppImage**, or the **.deb** on Ubuntu / Debian. iPhone and iPad: set up from ArkStore on your computer (Account › Set up iPhone).

### iPhone
- **ArkStore updates itself on the iPhone.** From this version on, when a new ArkStore is out, the iPhone shows "ArkStore X is available · Update". It installs the new version right there with LocalDevVPN connected, no computer needed. ArkStore closes and opens on the new version
- **Get installs with ArkStore itself.** On an iPhone set up from a computer, Get opens ArkStore's own installer. SideStore, TrollStore and the IPA are under "Other ways to install"
- **Clear errors in iPhone setup,** with Show details for the full error

To get this version on an iPhone the first time: ArkStore on your computer › Account › Set up iPhone › install ArkStore. Later versions update on the iPhone.
