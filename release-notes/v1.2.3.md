ArkStore on Android, Windows, macOS and Linux.

**Which file?** Android: **arm64-v8a** fits almost every phone (not sure? take **universal**). Windows: the **windows-x64-setup.exe** (or the **.msi**). Mac: the **.dmg** for your chip (**arm64** for Apple silicon, **x64** for Intel). Linux: the **.AppImage**, or the **.deb** on Ubuntu / Debian.

### New
- **Hundreds more apps** for Windows, macOS, Linux and Android. ArkStore now finds new apps on GitHub every night and lists the ones with an installable release
- **AI agents** (Apps → AI agents): MCP servers from the official MCP registry and Claude Code plugins, with the exact command to install each one in Claude Code, Codex or Claude Desktop, and a copy button
- **Connect an AI agent** (Account): let Claude or Codex search ArkStore, check whether an app already exists before building one, and publish your apps for you. Create and revoke agent tokens here
- **ArkStore plugin for Claude Code**: `/plugin marketplace add Ark-Devs/ArkStore`, then `/plugin install arkstore@arkstore`
