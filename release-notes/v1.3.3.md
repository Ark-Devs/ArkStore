ArkStore 1.3.3 for iPhone and iPad. This is an iPhone-only update: Android, Windows, macOS and Linux stay on [1.3.2](https://github.com/Ark-Devs/ArkStore/releases/tag/v1.3.2).

### iPhone
- **Use a pairing file you already have.** If ArkStore got onto your iPhone without ArkStore on a computer (for example with iloader or SideStore), Get no longer stops at "Set up once with a computer". Tap **Choose pairing file** and pick the one from iloader, SideStore's setup or JitterbugPair. ArkStore then signs and installs apps on the iPhone itself, with LocalDevVPN connected
- **Clearer LocalDevVPN step:** when ArkStore can't reach the iPhone, it now says why
- **Contact us** from Account: support@arkdevs.xyz, issues@arkdevs.xyz, admin@arkdevs.xyz and contact@arkdevs.xyz

To get it: install **ArkStore-1.3.3-ios.ipa** the same way you installed ArkStore, or update from inside ArkStore if it's already set up to install apps on the iPhone.
