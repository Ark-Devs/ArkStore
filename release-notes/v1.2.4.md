ArkStore on Android, Windows, macOS and Linux.

**Which file?** Android: **arm64-v8a** fits almost every phone (not sure? take **universal**). Windows: the **windows-x64-setup.exe** (or the **.msi**). Mac: the **.dmg** for your chip (**arm64** for Apple silicon, **x64** for Intel). Linux: the **.AppImage**, or the **.deb** on Ubuntu / Debian.

### New
- **Agents tab**: skills, Claude Code plugins and MCP servers for Claude, Codex and other AI agents, each with the command to install it
- **Agent skills**: hundreds of skills from GitHub (Anthropic, Hugging Face, Supabase, Trail of Bits and more), installed with one `npx skills add` command for Claude Code or Codex
- **Many more plugins**: every Claude Code plugin marketplace ArkStore knows about, with new ones found automatically each night
- Faster search across the agent catalog
