ArkStore is an Android app store for apps that live on GitHub. Install the APK that matches your phone (almost every phone from the last few years: **arm64-v8a**). Not sure? Take **universal**.

### New
- Download time: the progress ring shows how long is left, and app pages estimate the download from your phone's recent speed
- Downloads and installs are separate steps: close the installer early and the button becomes Install, no second download
- ArkStore offers to delete an installer once the app is installed, and Account lists every installer file with a one-tap clean-up
- Featured apps: App of the Day, the top of Apps, and first place in search and their category
- Downloads and confirmed installs are counted separately; developers see both in Studio
- Clear message when GitHub sign-in isn't set up on the server, and a fix for a sign-in race on Android

### Faster and smaller
- Per-CPU APKs, R8 code shrinking and compressed native code: the arm64 APK is 21 MB, down from 114 MB (universal: 39 MB)
- Only the icons and font weights the app uses are bundled, which also shortens startup
- Dot-grid and dotted-line details are drawn from tiny image tiles instead of live vector graphics, so scrolling stays smooth
- Stats use a clean grotesk; dot-matrix type stays on the headings

### Also
- Removed six unused packages carried over from the project template
